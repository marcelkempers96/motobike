Fuel stabiliser

Also called: fuel stabilizer, fuel additive, storage additive

Find this part →

Fuel stabiliser is a bottled additive that slows the ageing of petrol. Fuel left in a carburettor can turn to varnish in a few weeks, and a small amount goes bad faster than a large tank. The varnish blocks jets and passages and can make a cleaning job costly.

What it does

It keeps stored fuel from gumming. It can be used in every tank on a bike that is not used often.

Signs you need it

  • The bike stands more than a few weeks between rides.
  • Hard starting or stalling after standing: Will not start after standing for weeks or months.
  • Fuel that smells sour or looks dark: Old or stale fuel in the tank.

When to use it

Before any long stand, and in the tank of an engine used only now and then. Follow the instructions on the bottle for the amount.

What to match when buying

  • A stabiliser for petrol engines. Any common brand will do.
  • For ethanol blend fuel, check that the label allows it.
  • Do not use it as a cure for fuel that is already bad. Drain bad fuel first.

Using it

  • Pour it into the tank, then add fuel so it mixes. Run the engine for a few minutes so it reaches the carburettor.
  • See Protect stored fuel with a fuel stabiliser.
