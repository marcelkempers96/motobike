Thread locker

Also called: Loctite type, threadlock, screw lock, bolt locking compound

Find this part →

Thread locker is a liquid that is put on a thread before tightening. It sets and stops the fastener working loose.

When to use it

  • A nut or bolt that keeps coming loose, where the manual allows a thread locker.
  • Where the manual says to use it.

What to match when buying

  • There are several strengths. Choose the medium type for fasteners that must be undone later. A strong type is for fasteners that rarely come apart.
  • Use the standard type if you are not sure. A stronger one can be too hard to remove.

Using it

  • Clean and degrease the thread. Put a little on the bolt thread only. Tighten to the manual torque.
  • Locking washers and locknuts are other ways to stop loosening: Identify bolt strength, thread and locking types. If a locking washer or nut is scraped, it has been working: replace it.
  • Keep thread locker off bearings and seals.
  • Problem page: Nuts and bolts keep coming loose.
