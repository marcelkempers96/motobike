Yamaha MT-07: repairs, problems and specs

The MT-07 is a middleweight naked bike announced in 2014 with a 689 cc parallel twin built for linear torque, positioned below the triple-cylinder MT-09. It also has A2 licence versions limited to 35 kW, and a Y-AMT automated manual variant.
