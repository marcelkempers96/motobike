MOTORCYCLE
SPECIFICATIONS

Here are some motorcycle specifications. The first part is just a bunch of general specifications. These are the sizes of chains, batterys, tires, spark plugs, and the like, for current model motorcycles (1970-2001). Then, as I get the time, I'm going to add more and more specs on different bikes. I'll start with specs on bike that you might run across, but will have a hard time getting Info on. Like 1960's and 70's Japanese bikes, and grow from there. Enjoy!
