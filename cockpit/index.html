Cockpit

A rider’s-eye view of a 125 cc road motorcycle with every control working. Start it with the key ON, the stop switch at RUN and the gearbox in neutral (or the clutch pulled), then pull the clutch, select first and open the throttle while you let the clutch out. Every control works from the keyboard, so you can hold the clutch and the throttle at the same time.
