# inbox/

Drop **anything** here: models (`.glb`), renders (`.png`), illustrations (`.svg`), PDFs, notes.
No need to organise — it gets sorted into `assets/` afterwards.

This folder is **not deployed** (see `.vercelignore`), so raw dumps never go live by accident.

Tip: GitHub's web uploader takes files up to 25 MB each (100 MB via git). For a big batch,
drag the whole folder onto the GitHub "Add file → Upload files" page while viewing `inbox/`.
